# `MaqsData` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `MaqsData` product, three read-only SQLite readers (`Trails`, `Places`, `Roads`) and the shared corner formula. To support it, the curvature layer gains a `junctions` table and a `junction` column, and `MaqsCore` installs files readable after first unlock.

**Architecture:** Each reader is an actor over the open files of its layer. An internal store opens each file as an immutable read-only URI, checks its metadata and columns, and opens a set all or none. Queries run synchronously inside the actor and never suspend. Geometry (polyline6, haversine, bearings, local-plane projection) and the corner formula are internal pure functions; the formula is public as `Curvature.analyze`. The lookahead walks junction points (segment ends, plus the `junctions` rows when the file has them), applies the fork rule, and marks what comes after a guess.

**Tech Stack:** Swift 6.2 tools, Swift 6 language mode, iOS 18 / macOS 15; Foundation, SQLite3 (system library: FTS5, R\*Tree), CoreLocation (`CLLocationCoordinate2D` only), os; Swift Testing. Pipeline: Python via `uv`, pyosmium, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-10-26-maqs-data-design.md`

## Global Constraints

- `Package.swift`: add `.library(name: "MaqsData", targets: ["MaqsData"])`, `.target(name: "MaqsData", swiftSettings: warningsAsErrors)` with **no dependency**, and `.testTarget(name: "MaqsDataTests", dependencies: ["MaqsData", "MaqsTestSupport"], swiftSettings: warningsAsErrors)`. Tools 6.2, platforms and language modes unchanged, no `unsafeFlags`.
- `MaqsData` imports only Foundation, SQLite3, CoreLocation, os. Never `MaqsCore`, `MaqsTerrain` or `MapLibre`.
- The public signatures are the spec's *Public API* block. **Every throwing public method uses typed `throws(QueryError)`** (this plan's answer to the spec's builder's call). Every `public` symbol has a DocC comment; everything else is `internal`. No `try!`; no force unwrap outside tests; no `fatalError` on a recoverable path; no `@unchecked Sendable` without a written justification in a comment.
- Opening: URI `file:<percent-encoded path>?immutable=1`, flags `SQLITE_OPEN_READONLY | SQLITE_OPEN_URI`. Nothing in `MaqsData` writes a file.
- An error or log line names a file by its last path component only, never its full path.
- Logging: `Logger(subsystem: "com.lucavallin.maqs", category: "data")`. Query points, cone origins and road positions are logged only with `privacy: .private`. Queries are not logged at info.
- Constants, verbatim from the spec and `data-format.md`:
  - **Corner formula:** sphere radius `6_371_008.8` m; local plane `x = Δlon × 111_320 × cos(lat_B)`, `y = Δlat × 110_574`; vertex merge 5 m; collinear below `1e-9` m²; band weights 4 (< 30 m), 3 (< 60), 2 (< 100), 1 (< 175), 0 otherwise; corner cutoff 500 m.
  - **Cone:** `halfAngle` default 5, in `(0, 180]`; `maxDistance` default 100,000, in `(0, 500_000]`; places under 1 m from the origin are left out.
  - **Limits:** trail search `limit` 1…500, default 50; trail area 1…2,000, default 200; places area 1…5,000, default 500; cone `limit` at least 1 when given; difficulty range within 1…6; `segments(near:)` `within` 1…500 m, default 50, and `limit` 1…100, default 20; lookahead `distance` in `(0, 10_000]`, default 1,000.
  - **Lookup box:** the end-node R\*Tree box is ±1e-5°.
- The fork turn is measured over **20 m** either side of the node, or the whole stretch when it is shorter. This is a plan decision for the spec's builder's call.
- Fixtures: only `scripts/update-fixtures.sh`, `scripts/update-terrain-golden.sh` and `scripts/update-data-golden.sh` write `Tests/MaqsTestSupport/Fixtures/`, and the total stays under 8 MB. Tests build synthetic layer files in a `TemporaryDirectory`, never in the repository.
- `swift test --filter` takes the suite name (`PolylineTests`), never `MaqsDataTests/PolylineTests`. Swift Testing runs suites in parallel: one `TemporaryDirectory` per test, nothing global.
- Pipeline code: ruff clean (lint and format), type hints everywhere, `pathlib`, no `shell=True`.
- Commits: `type(scope): summary`, with a body when a decision was made. Never push; the controller pushes.

## Review Focus

1. **A coordinate with no fix** (`kCLLocationCoordinate2DInvalid` is −180, −180), NaN or infinity, passed as a search `near`, a cone origin, a `segments(near:)` position, a `RoadPosition.along` or a `Curvature.analyze` point, is `QueryError.invalidInput` before any SQL runs. It is never a crash and never an empty answer. Pinned in Tasks 6, 7, 8, 9 and 10.
2. **The same road in two installed files** (Triveneto and Veneto overlap) gives one `NearbySegment` per way. The lookahead builds the same path from both files as from one: branches are deduplicated by way id and direction, the first file winning, so no fake fork appears. Pinned in Tasks 9 and 10.
3. **Punctuation-only or FTS-hostile search text** (`"`, `*`, `-`, `'`, `NEAR(`, `AND`, `—`) returns `[]` or name matches. It never throws, even when quoting leaves FTS5 a phrase with no tokens. Pinned in Task 7.
4. **A file removed or replaced after opening** (`MaqsCore` updates a pack while a reader holds it) keeps answering from the old file. Pinned in Task 4.
5. **A rider exactly at a segment's end** (`along == length`, or `along` past it before clamping) continues onto the next segment, with distances counted from 0 there. It does not return an empty lookahead. Pinned in Task 10.

## Rollback, observability, cost

- **Rollback:**
  - The Swift product is additive; revert its commits.
  - The curvature additions are additive v1 changes (compatibility rule). Reverting them makes the next release's files lack them, and readers fall back to end-node links.
  - The `MaqsCore` change reverts to the platform default class.
  - No published release is touched. The next monthly build carries the new table.
- **Observability:**
  - `data` log category: each file opened (name, region, layer, row count) at info, and each rejection at error.
  - Every degraded answer is visible in its value: `geometryStatus`, `afterFork` with the fork's `reason`, `noContinuation`.
  - The `junctions` row count appears in `build-report.json` (`COUNT_TABLES`), so a build that loses the table shows 0 rows.
  - No alert applies to a client library.
- **Cost:**
  - **Pipeline:** one more pass over the kept ways' node ids per curvature build, measured on Veneto in Task 2.
  - **Release:** the curvature file grows by the `junctions` table, also measured in Task 2.
  - **CI:** `swift.yml` runs one more test target. No network calls in `MaqsData`.

### Task 1: The pipeline records junctions and the `junction` tag

**Files:**
- Modify: `pipeline/src/maqs/sqlite_out.py`, `pipeline/src/maqs/curvature/step.py`, `pipeline/tests/test_steps_curvature.py`

**Interfaces:**
- **DDL:** append `junction TEXT` as the last column of `segments`, after `geometry`, so the positional INSERT simply gains one value. Add the spec's table verbatim:
  ```sql
  CREATE TABLE junctions (segment_id INTEGER NOT NULL REFERENCES segments(id), node INTEGER NOT NULL, along_m REAL NOT NULL);
  CREATE INDEX junctions_node ON junctions(node);
  CREATE INDEX junctions_segment ON junctions(segment_id, along_m);
  ```
  `TABLES["curvature"]` gains `"junctions"`, and `COUNT_TABLES["curvature"]` becomes `("segments", "corners", "junctions")`.
- `SegmentRecord` gains `junction: str | None`, `nodes: list[int]` (located node ids, in way order) and `located: list[Coord]` (their coordinates, before the merge).
- `junction_rows(segments: Sequence[SegmentRecord]) -> list[tuple[int, int, float]]` returns `(segment_id, node, along_m)`, where `segment_id` is the list index + 1, ordered by segment then `along_m`.

The rule:
- A node counts as shared when it is in the located nodes of **two or more distinct** kept segments.
- Each segment gets one row per located index `i` in `1 … len(nodes) − 2` whose node is shared. A closed way's first and last index are its ends.
- `along_m`: when vertex `i` survived the merge, its distance along the merged geometry. Otherwise, the distance to the point nearest the node on the merged stretch between the kept vertices before and after `i`. The merged geometry is a subsequence of `located`: match it in order.

```swift
public enum QueryError: Error, Equatable, LocalizedError {
    case cannotOpen(file: String), wrongLayer(file: String, expected: String, found: String)
    case unsupportedSchemaVersion(file: String, version: Int), incompatibleFile(file: String, missing: String)
    case duplicateRegion(String), corruptData(file: String, detail: String), unreadable(file: String)
    case invalidInput(String), unknownSegment(Int64)
    static func sqlite(_ code: Int32, file: String) -> QueryError   // the mapping below
}
enum Layer: String, Sendable { case trails, places, curvature }
final class Connection {                       // not Sendable; owned by one actor; sqlite3_close_v2 on deinit
    init(url: URL) throws(QueryError)          // immutable URI; cannotOpen on failure
    let fileName: String
    func prepare(_ sql: String) throws(QueryError) -> Statement      // statements cached by SQL text
    func columns(of table: String) throws(QueryError) -> Set<String> // PRAGMA table_info; empty = no table
}
final class Statement {                        // bind(_:at:) for Int64, Double, String, nil; step() -> Bool; int64/double/text(at:), isNull(at:); reset()
}
struct LayerFile {                             // not Sendable
    let connection: Connection; let fileName: String; let region: String; let rowCount: Int
    let hasJunctions: Bool                     // curvature: the junctions table exists
    let hasJunctionColumn: Bool                // curvature: segments.junction exists
    static func open(_ url: URL, as layer: Layer) throws(QueryError) -> LayerFile
    static func openAll(_ urls: [URL], as layer: Layer) throws(QueryError) -> [LayerFile]   // all or none; duplicateRegion
}
```

**The mapping `QueryError.sqlite(code, file:)` (plan refinement):**
- `SQLITE_IOERR_SHORT_READ` (522) is `corruptData`, because the file is shorter than its contents claim.
- Any other `SQLITE_IOERR` (primary code 10, any extended code), `SQLITE_PERM` and `SQLITE_CANTOPEN` are `unreadable`.
- Everything else is `corruptData(file:, detail: "SQLite result code \(code)")`.

**Requirements per layer** (tables, then the columns read). Junctions are optional for curvature.
- **trails:** `metadata`; `trails` (`id`, `source`, `source_id`, `source_licence`, `source_date`, `osm_type`, `osm_id`, `ref`, `ref_rei`, `name`, `difficulty`, `difficulty_scheme`, `difficulty_value`, `network`, `operator`, `osmc_symbol`, `from_name`, `to_name`, `roundtrip`, `survey_date`, `website`, `length_m`, `ascent_m`, `descent_m`, `min_lon`, `min_lat`, `max_lon`, `max_lat`, `geometry`, `geometry_status`, `secondary_of`); `trails_fts`; `trails_rtree`.
- **places:** `metadata`; `places` (every column of the DDL); `places_rtree`.
- **curvature:** `metadata`; `segments` (every v1 column); `corners` (every column); `segments_rtree`.

**Open checks, in order:**
1. `metadata` exists (else `incompatibleFile(missing: "metadata")`).
2. Exactly one row (else `corruptData`).
3. `layer` matches (else `wrongLayer`).
4. `schema_version == 1` (else `unsupportedSchemaVersion`).
5. Required tables and columns exist (else `incompatibleFile(missing: "trails.ref_rei")` style).

The row count is that of the layer's main table. `openAll` logs each opened file at info and each rejection at error.

enum Polyline6 {
    /// Latitude first in the text; returns coordinates. `PolylineError` is mapped to corruptData by callers (they know the file).
    static func decode(_ text: Substring) throws(PolylineError) -> [CLLocationCoordinate2D]

**The walk** is the spec's *Corners ahead* steps 1–5, with junction points restricted to segment ends in this task (Task 11 adds the `junctions` rows). This task's rules:
- **Validation and lookup:**
  - `distance` must be in `(0, 10_000]` and `along` finite, else `invalidInput`. `along` is clamped to `0…length`.
  - An id in no open file is `unknownSegment`.
  - The starting segment is taken from the open files by id, not from the passed value.
- **Corners:**
  - Each (segment, ordinal) is reported at most once.
  - A corner is reported when its apex distance ahead is in `[0, distance]`.
  - `entry` and `exit` are relative to the position. For travel against the drawing direction, distances flip and turns swap.
  - `afterFork` is true when a fork lies before the corner's apex on the path.
- **Branches at a node:**
  - Found through `segments_rtree` at the node's coordinate (the stored geometry's end vertex), ±1e-5°, filtered by `start_node`/`end_node`.
  - Deduplicated by (way id, direction), the first file winning (Review Focus 2).
  - Branches against the effective one-way are dropped. The starting segment's first step is exempt.
- **Covered stretches:** per way id, a list of `[from, to]` intervals in drawing-direction metres. A branch is on the path when the midpoint of its first stretch lies in one. With segment ends only, the first stretch is the whole segment.
- **Fork rule:**
  - Narrow by `ref` (trimmed, whitespace collapsed, case ignored, whole string), then `name`, then `highway`, each only when at least one candidate is left.
  - The compared `ref` and `name` are the last non-empty ones on the path.
  - Then the smallest absolute turn: the bearing over 20 m before the node, against the bearing over 20 m along the branch.
  - Ties go to the lower way id, then `forward`.
  - `reason` is the last rule that narrowed the set, else `smallestTurn`.
  - `alternatives` are the branches not chosen, in the same order.
- **Ends:**
  - No branch: `noContinuation(at:)`, the node's distance ahead.
  - `reachedDistance` once the walk covers `distance`.
  - `along == length` with the direction leading off the end starts at the node, distance 0 (Review Focus 5).
