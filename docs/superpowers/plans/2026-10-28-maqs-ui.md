# `MaqsUI` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `MaqsUI` product: a SwiftUI map over MapLibre Native that draws from installed packs inside them and streams outside, with a tile gateway that pauses on 429, the bundled glyphs, sprite and muted default styles, lines, markers, the trails and places overlays, camera and location, the attribution view, and the demo app.

**Architecture:** `MaqsMap` (`@MainActor @Observable`) holds what the app wants drawn and what the map reports. A pure `StyleAssembler` turns the base style (bundled or the app's) plus the online sources, installed overlays and content layers into one style JSON; `MaqsMapView` hands it to `MLNMapView(frame:styleJSON:)` and, after each load, sets the GeoJSON data, the marker images and the overlay selection. Tiles reach MapLibre through `TileGateway`, a `URLProtocol` on MapLibre's own session: a pure `TileRouter` sends each request to an installed region's archive (read by `MaqsPMTiles`, the reader moved out of `MaqsTerrain`), to the network through the gateway's session with the rate-limit pause, or to a base pack when online cannot answer.

**Tech Stack:** Swift 6.2 tools, Swift 6 language mode, iOS 18 (macOS 15 for the pure parts and the other products); MapLibre Native iOS 6.31.0 (SPM binary, iOS only); Foundation, SwiftUI, UIKit, CoreLocation, Network, Synchronization, os; Swift Testing. Asset transform: Python via `uv`, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-10-28-maqs-ui-design.md` (approved by the owner on 2026-10-28)

## Global Constraints

- **`Package.swift`:**
  - `dependencies: [.package(url: "https://github.com/maplibre/maplibre-gl-native-distribution", "6.31.0"..<"7.0.0")]`. `Package.resolved` comes from `swift package resolve` and is committed; never hand-edited.
  - `.library(name: "MaqsUI", targets: ["MaqsUI"])`.
  - `.target(name: "MaqsPMTiles", swiftSettings: warningsAsErrors)` with no dependency and no product. `MaqsTerrain` gains the dependency `"MaqsPMTiles"`.
  - `.target(name: "MaqsUI", dependencies: ["MaqsCore", "MaqsPMTiles", .product(name: "MapLibre", package: "maplibre-gl-native-distribution", condition: .when(platforms: [.iOS]))], resources: [.copy("Resources")], swiftSettings: warningsAsErrors)`.
  - `.testTarget(name: "MaqsPMTilesTests", dependencies: ["MaqsPMTiles", "MaqsTestSupport"], swiftSettings: warningsAsErrors)` and `.testTarget(name: "MaqsUITests", dependencies: ["MaqsUI", "MaqsCore", "MaqsData", "MaqsTestSupport"], swiftSettings: warningsAsErrors)`.
  - `MaqsTestSupport` gains the dependency `"MaqsPMTiles"`, for the test archive writer.
  - Tools version, platforms and language modes unchanged; no `unsafeFlags`.
- **Platform guards:** every file that imports MapLibre is wrapped in `#if canImport(MapLibre)`; UIKit and SwiftUI code in `#if canImport(UIKit)`. Each of `MaqsUI` and `MaqsUITests` keeps at least one unguarded file, so the modules exist on macOS (spike result, 2026-10-28). Pure logic (style assembly, routing, pause, credits, offer, GeoJSON, the gateway's `URLProtocol`) is Foundation-only and is tested by `swift test` on macOS.
- **Imports:** `MaqsUI` imports Foundation, SwiftUI, UIKit, CoreLocation, Network, Synchronization, os, MapLibre, `MaqsCore` and `MaqsPMTiles`, nothing else. `MaqsCore`, `MaqsData` and `MaqsTerrain` never import `MaqsUI` or MapLibre. No public `MaqsUI` symbol exposes a MapLibre type. `Examples/` never imports MapLibre (the existing `guards` check covers it).
- **Cross-module access** uses Swift's `package` modifier, never `public`: `MaqsConfiguration.fullUserAgent` becomes `package`; `MaqsPMTiles` exposes `package` types only.
- **Public API** is the spec's *Public API* block, with the refinements in this plan's Interfaces blocks. Every `public` symbol has a DocC comment; everything else is `internal`. No `try!`; no force unwrap outside tests; no `fatalError` on a recoverable path; `@unchecked Sendable` only with a comment that justifies it.
- **MapLibre rules** (verified 2026-10-28, spec *Facts*):
  - Create the map only with `MLNMapView(frame:styleJSON:)`, never `MLNMapView(frame:)` and never a nil style.
  - The delegate conformance is `@preconcurrency MLNMapViewDelegate` on a `@MainActor` coordinator. Every MapLibre call runs on the main actor.
  - Every source and layer id `MaqsUI` adds starts with `maqs-`; `StyleAssembler` rejects an app style that already uses that prefix, so no duplicate id ever reaches MapLibre (an uncatchable Objective-C exception).
  - Never call `invalidateAmbientCache`. Never call the deprecated `setVisibleCoordinateBounds(_:edgePadding:animated:)`.
  - Mutate `MLNNetworkConfiguration.sharedManager.sessionConfiguration` in place (User-Agent, `protocolClasses`), once per process, before the first `MLNMapView`; never replace it.
  - `shouldRequestAuthorizationToUseLocationServices = false`; `showsCompassView`, `showsLogoView`, `showsAttributionButton` and `showsScale` all false.
- **Constants, verbatim from the spec:**
  - **Pause:** 60 s after a 429, doubled per further 429 up to 900 s, reset by the first success after a pause; a 429 or a success during a pause changes nothing (as `MaqsTerrain`'s `CoolDown`).
  - **Gateway:** request timeout 15 s; an empty answer is HTTP 204; the reserved host when there is no online source is `maqs.invalid` (RFC 2606), templates `https://maqs.invalid/basemap/{z}/{x}/{y}` and `https://maqs.invalid/terrain/{z}/{x}/{y}`.
  - **Colours** (light / dark): base `#EEF2F7`/`#191F28`, green `#D0EEE9`/`#14282B`, water `#C1E5F6`/`#122442`, road `#FFFFFF`/`#2E343E`, casing `#FFFFFF`/`#191F28`, casing edge `#101620`/none, hidden line `rgba(16,22,32,0.5)`/`rgba(230,237,243,0.5)`, location `#1C6CF7`/`#61D0FF`.
  - **Lines:** active 5 pt accent; casing 8 pt; other solid 4 pt grey (the hidden-line colour at full opacity: `#8A8F96`/`#737980`, *plan decision*); hidden 3 pt, `line-dasharray` `[1.333, 1.667]` (4 pt dash, 5 pt gap at 3 pt width), no casing; glow: accent at 0.6 opacity, 12 pt, `line-blur` 6, dark styles only (*plan decision* on the glow values). Round caps and joins.
  - **Markers:** 30 pt circle, 2 pt white ring, shadow 0 1 3 at 25 % black; hit rect 44 pt; selected 1.25× with a 4 pt accent halo at 35 % opacity; labels Noto Sans Bold 13, halo 2 pt in the casing colour.
  - **Fonts:** stacks `noto_sans_regular` and `noto_sans_bold`; glyph ranges `0-255` … `768-1023` and `8192-8447`.
  - **Pinned assets** (GitHub release digests, read 2026-10-28):
    - `https://github.com/versatiles-org/versatiles-fonts/releases/download/v3.0.0/noto_sans.tar.gz`, SHA-256 `f58be6be2eb3d127b6ff1c90d828b69ff4807d1d88cd13a43930943fda0e334e`, 31,304,823 bytes.

- **Logging:** `Logger(subsystem: "com.lucavallin.maqs", category: "ui")`. Never a full URL, a query string, tile content or a position; tile coordinates only with `privacy: .private`; files by their last path component.
- **Privacy and requests:** no request to any host but the online templates' hosts; none at all with `onlineTiles` false; none inside an installed region; nothing that disables caching.
- **Tests:** Swift Testing. Wait on observable state with a `.timeLimit`, never a sleep, and never race a `StubResponse` delay (CLAUDE.md); hold stub answers with `StubGate` and release in a `defer`. One `StubServer` and one `TemporaryDirectory` per test. `swift test --filter` takes the suite name.
- **No app knowledge:** nothing in code, docs, tests, assets or commits names or describes a consuming app.
- **Pipeline code** (the style transform): ruff clean, type hints everywhere, `pathlib`, no `shell=True`.

## Review Focus

1. **A style load drops every image and every GeoJSON payload** (MapLibre clears run-time state on load), including the loads MapLibre starts on its own and the light/dark swap. After any `mapView(_:didFinishLoading:)`, lines, markers, marker images and the overlay selection are back. Pinned in Task 11.
2. **Malformed or hostile tile URLs reaching the gateway** (`z` above 22, `x` or `y` outside `0..<2^z`, negative or non-numeric parts, extra path segments, a query string, another host) never crash and never read an archive: they pass through untouched or get a 404. Pinned in Tasks 6 and 7.
3. **A pack removed or updated while the map shows it.** An archive the gateway already opened stays readable (the descriptor is held), the next pack list drops it, and an overlay source is replaced by a style rebuild, never left pointing at a deleted file. Pinned in Tasks 7 and 10.
4. **Duplicate or odd app input:** two lines or markers with the same id (the last wins), an `activeLineID` or `selectedMarkerID` that names nothing (no accent, no crash), an empty coordinate list, a line with one point, NaN coordinates (dropped, logged at debug). Pinned in Task 9.
5. **Offline at first launch with nothing installed and an empty cache.** The map loads its style, shows the background (and a registered base pack's tiles at zoom 10 and below), reports `connectivity == .offline` and no `lastError`, and sends no request. Pinned in Task 10.

## Rollback, observability, cost

- **Rollback:**
  - `MaqsUI`, the demo and the assets are additive; revert their commits.
  - The `MaqsPMTiles` move is a refactor with `MaqsTerrain`'s public API unchanged, and reverts on its own.
  - No data file, manifest, release or `sources.json` changes.
- **Observability:**
  - `ui` log: style loads and failures; pack-list changes (ids only); gateway counters once a minute while non-zero (local, empty, online, base, failed); the start and end of each pause.
  - In the API: `lastError`, `onlineTilesPaused`, `connectivity`.
  - No alert applies to a client library.
- **Cost:**
  - **Apps:** linking `MaqsUI` adds the MapLibre framework, about 10 MB compressed in the xcframework, plus about 1.5 MB of bundled assets (measured in Task 4).
  - **Provider:** inside installed regions the map sends no tile request, where today any map would. Outside them, hillshade adds the view's terrain tiles, about four to six 512 px tiles beside the basemap's. A 429 stops the map's requests for at least 60 s, where MapLibre alone retries every tile every 5 s.
  - **CI:** two more test targets; `swift.yml`'s simulator job also builds the demo, about a minute of macOS time. `swift build` on macOS downloads the 10.3 MB MapLibre binary.
