# Swift package skeleton and `MaqsCore` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `Maqs` Swift package with its first product, `MaqsCore`: manifest and `sources.json` clients, region discovery through the latest data release, verified downloads with atomic install, and observable state for SwiftUI, with CI on macOS and the iOS Simulator.

**Architecture:** One public `actor Maqs` owns small internal parts (manifest client, sources client, pack store, download session, installer) and publishes a `@MainActor @Observable MaqsState`. Everything the network returns is parsed strictly and validated before use; every downloaded file is SHA-256 verified before it becomes visible; `pack.json` is the only thing readers trust. Tests run against a stub `URLProtocol` and committed fixtures built from the `test` region.

**Tech Stack:** Swift 6.2 tools, Swift 6 language mode, iOS 18 / macOS 15, Foundation (`URLSession`, `JSONDecoder`), CryptoKit (SHA-256), Synchronization (`Mutex`), Observation, `os.Logger`, Swift Testing. No third-party dependency.

**Spec:** `docs/superpowers/specs/2026-10-16-maqs-core-design.md`

## Global Constraints

- `Package.swift`: `swift-tools-version: 6.2`, `platforms: [.iOS(.v18), .macOS(.v15)]`, `swiftLanguageModes: [.v6]`, every target `swiftSettings: [.treatAllWarnings(as: .error)]`; no `unsafeFlags`; no dependency.
- `MaqsCore` imports only Foundation, CryptoKit, Synchronization, Observation, os. Never SQLite, never MapLibre.
- Every `public` symbol has a DocC comment (`///`). Everything else is `internal`. No `try!`, no force unwrap outside tests, no `fatalError` on a recoverable path, no `@unchecked Sendable`.
- Errors are the typed enums of the spec (`MaqsError`, `ManifestError`, `DownloadError`, `StorageError`, `SourcesError`) with `LocalizedError` descriptions that say what to do. `throws`, never `nil`, for a failure.
- Logging: `Logger(subsystem: "com.lucavallin.maqs", category: "core")`; never a URL with a query string, never file contents.
- The package's own default URLs: manifest `https://github.com/lucavallin/maqs/releases/latest/download/manifest.json`, sources `https://raw.githubusercontent.com/lucavallin/maqs/main/config/sources.json`. No tile or DEM provider URL anywhere in Swift.
- Every request carries `User-Agent: <app string> Maqs/0.1.0`; the session keeps HTTP caching on and never sends `Cache-Control: no-cache`.
- Every manifest entry URL must be `https` with the same host as the configured manifest URL; otherwise the manifest is rejected.
- Readable schema versions: `[1]` for every layer, in one table (`ReadableVersions.table`).
- Fixtures: committed under `Tests/MaqsTestSupport/Fixtures/`, total under 8 MB (`du -sk` ≤ 8192), regenerated only by `scripts/update-fixtures.sh`. The only binary data in git.
- Commits: `type(scope): summary`, no attribution trailer of any kind. Never push; the controller pushes.
- Commands that prove a task: `swift build` and `swift test` from the repository root (both must print no warning); the named filter for the task's suite.
- Date handling: `created_at` and `osm_timestamp` are ISO 8601 UTC with seconds; `data_date` is `YYYY-MM-DD` parsed as a UTC midnight `Date`.

## Review Focus

1. A region whose `name` object has a third language key (`"de"`) keeps all keys in `PackSummary.names`. Pinned in Task 6 (`CatalogTests`, "names keep every language key").
2. A region that lacks a layer the app configured (`terrain-hd` is optional in the schema) shows no entry for that layer, no error, and its status ignores the missing layer. Pinned in Task 6 ("a layer the manifest does not offer is absent, not an error").
3. A stale or corrupt file already sitting in `downloads/<file>` (from a crash or an old release) must not block the pack forever: its hash is checked, it is deleted on mismatch and downloaded again. Pinned in Task 10 ("a corrupt leftover download is replaced").
4. Two concurrent `install` calls for the same pack perform one install and both callers return when it is done. Pinned in Task 11 ("concurrent installs of one pack are one install").
5. An unwritable `storageDirectory` is `StorageError.cannotCreateDirectory` from `Maqs.init`, not a crash. Pinned in Task 5 ("an unwritable root is a typed error").

Spec refinements made while planning (recorded in ADR 0014 by Task 12):
- `Maqs.init` is `@MainActor` and synchronous `throws`, so it can create `MaqsState` directly.
- A bundled base pack is registered in memory per launch, not persisted: the app bundle's path changes across app updates, so a stored path would go stale. `InstalledFile.sha256` and `dataDate` are therefore optional (nil for bundled files).
- `downloads/` keeps completed or partial files between launches (they are hashed before use); the launch sweep removes only files under `packs/<id>/` that `pack.json` does not name, and stray `pack.json.tmp`.
- Fixture location is `Tests/MaqsTestSupport/Fixtures/` (resources must sit under the target's path; verified 2026-10-16 with a spike).
- Invalid manifests are not files: `Fixtures.manifestJSON(mutating:)` derives each rejected shape from the real fixture manifest in the test, so the cases cannot drift from the format.

`Sources/MaqsCore/MaqsConfiguration.swift`:

```swift
import Foundation

/// Everything an app tells `MaqsCore` once, when it creates its ``Maqs`` instance.
public struct MaqsConfiguration: Sendable {
    /// The layers this app needs. Only these are shown in the catalog and downloaded.
    public var layers: Set<Layer>
    /// An app-identifying `User-Agent` prefix such as `"MyApp/1.2 (iOS)"`. The package appends its own token.
    /// Free tile providers block generic agents; this is required.
    public var userAgent: String
    /// `false` turns every online tile and DEM request off (ADR 0008): ``Maqs/onlineSources`` is then `nil`.
    /// `manifest.json` and `sources.json` fetches stay allowed; they carry no position.
    public var onlineTiles: Bool = true
    /// A background `URLSession` identifier. Set it on iOS so downloads survive suspension;
    /// `nil` uses a foreground session (macOS, tests).
    public var backgroundSessionIdentifier: String?
    /// Where the latest manifest is read from. Only this file is read through `latest`.
    public var manifestURL = URL(string: "https://github.com/lucavallin/maqs/releases/latest/download/manifest.json")!
    /// Where the online providers file is read from.
    public var sourcesURL = URL(string: "https://raw.githubusercontent.com/lucavallin/maqs/main/config/sources.json")!
    /// The storage root. `nil` means `Application Support/Maqs` in the app's container.
    public var storageDirectory: URL?
    /// How old a cached manifest may be before ``Maqs/RefreshPolicy/ifStale`` fetches again.
    public var catalogMaxAge: Duration = .seconds(86_400)

    /// Test seam: a stub `URLProtocol` is injected through `protocolClasses`. Ignored for background sessions.
    var urlSessionConfiguration: URLSessionConfiguration = .default
    /// Test seam: the clock used for staleness.
    var now: @Sendable () -> Date = { Date() }

    /// Creates a configuration with the two required values; every other field has a default.
    public init(layers: Set<Layer>, userAgent: String) {
        self.layers = layers
        self.userAgent = userAgent
    }

    /// The full `User-Agent` header value: the app's string followed by the package token.
    var fullUserAgent: String { "\(userAgent) \(MaqsVersion.userAgentToken)" }
}
```

The two `URL(string:)!` are compile-time constants of well-formed literals; this is the one force unwrap the conventions allow, and a test pins both parse.

`Tests/MaqsTestSupport/Sources/StubServer.swift`:

```swift
import Foundation
import Synchronization

/// One scripted HTTP response.
public struct StubResponse: Sendable {
    public var status: Int
    public var headers: [String: String]
    public var body: Data
    public init(status: Int = 200, headers: [String: String] = [:], body: Data = Data()) {
        self.status = status; self.headers = headers; self.body = body
    }
}

/// Routes requests of one `URLSession` to scripted responses, with no network.
///
/// Each server has an id that travels in an `X-Maqs-Stub` header added by its `configuration`, so tests
/// running in parallel never see each other's routes. Download tasks and data tasks both go through it.
public final class StubServer: Sendable {
    public typealias Handler = @Sendable (URLRequest) -> StubResponse

    public let id = UUID().uuidString
    private let routes = Mutex<[String: Handler]>([:])
    private let seen = Mutex<[URLRequest]>([])

    public init() { StubURLProtocol.register(self) }
    deinit { StubURLProtocol.unregister(id) }

    /// Scripts the response for an absolute URL (query string included).
    public func route(_ url: URL, _ handler: @escaping Handler) {
        routes.withLock { $0[url.absoluteString] = handler }
    }

    /// Scripts a fixed response for an absolute URL.
    public func route(_ url: URL, status: Int = 200, headers: [String: String] = [:], body: Data) {
        route(url) { _ in StubResponse(status: status, headers: headers, body: body) }
    }

    /// Every request this server answered, in order.
    public var requests: [URLRequest] { seen.withLock { $0 } }

    /// A foreground session configuration whose requests all reach this server.
    public var configuration: URLSessionConfiguration {
        let configuration = URLSessionConfiguration.ephemeral
        configuration.protocolClasses = [StubURLProtocol.self]
        configuration.httpAdditionalHeaders = ["X-Maqs-Stub": id]
        return configuration
    }

    func respond(to request: URLRequest) -> StubResponse {
        seen.withLock { $0.append(request) }
        guard let url = request.url, let handler = routes.withLock({ $0[url.absoluteString] }) else {
            return StubResponse(status: 404)
        }
        return handler(request)
    }
}

final class StubURLProtocol: URLProtocol {
    private static let servers = Mutex<[String: StubServer]>([:])

    static func register(_ server: StubServer) { servers.withLock { $0[server.id] = server } }
    static func unregister(_ id: String) { servers.withLock { $0[id] = nil } }

    override class func canInit(with request: URLRequest) -> Bool {
        request.value(forHTTPHeaderField: "X-Maqs-Stub") != nil
    }

    override class func canonicalRequest(for request: URLRequest) -> URLRequest { request }

    override func startLoading() {
        guard let id = request.value(forHTTPHeaderField: "X-Maqs-Stub"),
              let server = Self.servers.withLock({ $0[id] }),
              let url = request.url
        else {
            client?.urlProtocol(self, didFailWithError: URLError(.badURL))
            return
        }
        let stub = server.respond(to: request)
        var headers = stub.headers
        headers["Content-Length"] = String(stub.body.count)
        let response = HTTPURLResponse(url: url, statusCode: stub.status, httpVersion: "HTTP/1.1", headerFields: headers)!
        client?.urlProtocol(self, didReceive: response, cacheStoragePolicy: .notAllowed)
        if !stub.body.isEmpty { client?.urlProtocol(self, didLoad: stub.body) }
        client?.urlProtocolDidFinishLoading(self)
    }

    override func stopLoading() {}
}
```

`Tests/MaqsTestSupport/Sources/Fixtures.swift`:

```swift
import Foundation

/// Access to the committed test-region outputs and the `data-ci` manifest.
public enum Fixtures {
    public struct Missing: Error, CustomStringConvertible {
        public let path: String
        public var description: String { "fixture not found: \(path)" }
    }

    /// The manifest URL every fixture-driven test uses; its host matches the fixture entry URLs.
    public static let manifestURL = URL(string: "https://github.com/lucavallin/maqs/releases/latest/download/manifest.json")!

    /// A fixture by path relative to `Fixtures/` (`"test/test-trails.v1.sqlite"`).
    public static func url(_ relativePath: String) throws -> URL {
        let parts = relativePath.split(separator: "/").map(String.init)
        let name = parts.last ?? relativePath
        let subdirectory = (["Fixtures"] + parts.dropLast()).joined(separator: "/")
        guard let url = Bundle.module.url(forResource: name, withExtension: nil, subdirectory: subdirectory) else {
            throw Missing(path: relativePath)
        }
        return url
    }

    /// The `data-ci` manifest, byte for byte.
    public static func manifestData() throws -> Data {
        try Data(contentsOf: url("manifest.json"))
    }

    /// The fixture manifest after an in-place edit of its JSON object, re-encoded.
    public static func manifestJSON(mutating edit: (inout [String: Any]) throws -> Void) throws -> Data {
        var object = try JSONSerialization.jsonObject(with: manifestData()) as? [String: Any] ?? [:]
        try edit(&object)
        return try JSONSerialization.data(withJSONObject: object, options: [.sortedKeys])
    }

    /// Every `url` in a manifest, with the `file` it names.
    public static func entryURLs(in manifest: Data) throws -> [(url: URL, file: String)] {
        let object = try JSONSerialization.jsonObject(with: manifest) as? [String: Any] ?? [:]
        var result: [(URL, String)] = []
        func walk(_ packs: Any?) {
            for pack in packs as? [[String: Any]] ?? [] {
                for entries in (pack["layers"] as? [String: [[String: Any]]] ?? [:]).values {
                    for entry in entries {
                        if let s = entry["url"] as? String, let url = URL(string: s), let file = entry["file"] as? String {
                            result.append((url, file))
                        }
                    }
                }
            }
        }
        walk(object["regions"])
        walk(object["base"])
        return result
    }

    /// Serves `manifest` (default: the fixture manifest) at ``manifestURL`` and each entry URL from the
    /// fixture file of the same name. The base pack's file is not committed, so its URL serves
    /// `test/test-basemap.v1.pmtiles`; tests that install a base pack rewrite its `sha256` and `bytes` first.
    public static func serveRelease(on server: StubServer, manifest: Data? = nil, etag: String? = "\"fixture-etag\"") throws {
        let manifest = try manifest ?? manifestData()
        var headers: [String: String] = ["Content-Type": "application/json"]
        if let etag { headers["ETag"] = etag }
        server.route(manifestURL) { request in
            if let etag, request.value(forHTTPHeaderField: "If-None-Match") == etag {
                return StubResponse(status: 304, headers: ["ETag": etag])
            }
            return StubResponse(status: 200, headers: headers, body: manifest)
        }
        for (url, file) in try entryURLs(in: manifest) {
            let local = file.hasPrefix("base-") ? "test/test-basemap.v1.pmtiles" : "test/\(file)"
            let data = try Data(contentsOf: try Self.url(local))
            server.route(url, body: data)
        }
    }

    /// SHA-256 and size of a fixture, for tests that rewrite manifest entries.
    public static func digest(_ relativePath: String) throws -> (sha256: String, bytes: Int) {
        let data = try Data(contentsOf: url(relativePath))
        return (SHA256Hex.hex(of: data), data.count)
    }
}
```

```swift
import Foundation

/// Every error `MaqsCore` throws, by subsystem.
public enum MaqsError: Error, LocalizedError, Sendable, Equatable {
    case manifest(ManifestError)
    case download(DownloadError)
    case storage(StorageError)
    case sources(SourcesError)

    public var errorDescription: String? {
        switch self {
        case .manifest(let e): e.errorDescription
        case .download(let e): e.errorDescription
        case .storage(let e): e.errorDescription
        case .sources(let e): e.errorDescription
        }
    }
}

/// Why a manifest was not accepted. The previous cached manifest stays in use.
public enum ManifestError: Error, LocalizedError, Sendable, Equatable {
    /// `manifest_version` is one this package does not read.
    case unsupportedVersion(Int)
    /// The JSON does not match the format; the message names the field, never the content.
    case invalid(String)
    /// An entry URL is not `https`.
    case insecureURL(String)
    /// An entry URL has another host than the manifest URL.
    case foreignHost(String)
    /// The fetch failed; the status code when there was a response.
    case network(statusCode: Int?)
    /// The server answered 429.
    case rateLimited

    public var errorDescription: String? {
        switch self {
        case .unsupportedVersion(let v): "This data release (manifest version \(v)) needs a newer app. Update the app."
        case .invalid(let what): "The map data index could not be read (\(what)). Try again later."
        case .insecureURL(let url): "The map data index points at a non-HTTPS address (\(url)) and was rejected."
        case .foreignHost(let url): "The map data index points outside its own host (\(url)) and was rejected."
        case .network(let code): "The map data index could not be fetched\(code.map { " (HTTP \($0))" } ?? ""). Check the connection and try again."
        case .rateLimited: "Too many requests to the data host. Try again in a few minutes."
        }
    }
}

/// Why a pack was not installed. Nothing already installed changes.
public enum DownloadError: Error, LocalizedError, Sendable, Equatable {
    case checksumMismatch(file: String)
    case sizeMismatch(file: String)
    case network(statusCode: Int?)
    case cancelled
    /// Every version of this layer is newer than the package reads.
    case layerUnreadable(Layer)
    /// The catalog does not list this pack; refresh the catalog.
    case notInCatalog(PackID)
    /// `install` was called before any catalog was loaded.
    case noCatalog

    public var errorDescription: String? {
        switch self {
        case .checksumMismatch(let f): "\(f) did not match its checksum and was discarded. Try the download again."
        case .sizeMismatch(let f): "\(f) had an unexpected size and was discarded. Try the download again."
        case .network(let code): "The download failed\(code.map { " (HTTP \($0))" } ?? ""). Check the connection and try again."
        case .cancelled: "The download was cancelled."
        case .layerUnreadable(let layer): "The \(layer.rawValue) layer needs a newer app. Update the app."
        case .notInCatalog(let id): "\(id) is not in the current catalog. Refresh and try again."
        case .noCatalog: "Load the catalog before installing."
        }
    }
}

    }
}

        }
    }
}
```

```swift
import Foundation

/// `manifest.json` as published (`docs/data-format.md`, `manifest_version` 1). Internal: apps see ``Catalog``.
struct Manifest: Decodable, Sendable, Equatable {
    let manifestVersion: Int
    let createdAt: Date
    let release: String
    let shortbreadVersion: String
    let attribution: [ManifestAttribution]
    let regions: [ManifestRegion]
    let base: [ManifestBasePack]

    enum CodingKeys: String, CodingKey {
        case manifestVersion = "manifest_version", createdAt = "created_at", release
        case shortbreadVersion = "shortbread_version", attribution, regions, base
    }

    init(from decoder: any Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        manifestVersion = try c.decode(Int.self, forKey: .manifestVersion)
        createdAt = try c.decode(ISO8601Seconds.self, forKey: .createdAt).date
        release = try c.decode(String.self, forKey: .release)
        shortbreadVersion = try c.decode(String.self, forKey: .shortbreadVersion)
        attribution = try c.decode([ManifestAttribution].self, forKey: .attribution)
        regions = try c.decode([ManifestRegion].self, forKey: .regions)
        base = try c.decodeIfPresent([ManifestBasePack].self, forKey: .base) ?? []
    }

    /// The one version this package reads.
    static let supportedVersion = 1

    /// Decodes and validates a manifest. Unknown fields, unknown layer keys and unknown roles pass through;
    /// a wrong type, a missing required field, a non-HTTPS entry URL or a foreign host is an error.
    static func decode(_ data: Data, manifestHost: String) throws -> Manifest {
        struct Probe: Decodable { let manifest_version: Int }
        let version: Int
        do {
            version = try JSONDecoder().decode(Probe.self, from: data).manifest_version
        } catch {
            throw ManifestError.invalid("manifest_version missing or not an integer")
        }
        guard version == supportedVersion else { throw ManifestError.unsupportedVersion(version) }
        let manifest: Manifest
        do {
            manifest = try JSONDecoder().decode(Manifest.self, from: data)
        } catch let error as DecodingError {
            throw ManifestError.invalid(error.fieldDescription)
        } catch {
            throw ManifestError.invalid("not valid JSON")
        }
        for entry in manifest.allEntries {
            guard entry.url.scheme?.lowercased() == "https" else {
                throw ManifestError.insecureURL(entry.url.absoluteString)
            }
            guard entry.url.host()?.lowercased() == manifestHost.lowercased() else {
                throw ManifestError.foreignHost(entry.url.absoluteString)
            }
        }
        return manifest
    }

    var allEntries: [ManifestEntry] {
        regions.flatMap { $0.layers.values.flatMap { $0 } } + base.flatMap { $0.layers.values.flatMap { $0 } }
    }
}

struct ManifestAttribution: Decodable, Sendable, Equatable {
    let text: String
    let licence: String
    let url: URL
    /// Layer names as strings: an unknown name is kept here and ignored downstream.
    let layers: [String]
}

struct ManifestRegion: Decodable, Sendable, Equatable {
    let id: String
    let name: [String: String]
    let bbox: [Double]
    /// Keyed by manifest layer name; unknown keys are kept and ignored by ``entries(for:)``.
    let layers: [String: [ManifestEntry]]

    func entries(for layer: Layer) -> [ManifestEntry]? { layers[layer.rawValue] }
}

struct ManifestBasePack: Decodable, Sendable, Equatable {
    let id: String
    let regions: [String]
    let maxZoom: Int
    let layers: [String: [ManifestEntry]]

    enum CodingKeys: String, CodingKey { case id, regions, maxZoom = "max_zoom", layers }

    func entries(for layer: Layer) -> [ManifestEntry]? { layers[layer.rawValue] }
}

struct ManifestEntry: Decodable, Sendable, Equatable {
    let layerSchemaVersion: Int
    let file: String
    let url: URL
    let bytes: Int64
    let sha256: String
    /// `data_date`, as UTC midnight.
    let dataDate: Date
    let osmTimestamp: Date?
    /// `nil` for the main file, `"overlay"` for a trails or places tile file; anything else is ignored by selection.
    let role: String?

    enum CodingKeys: String, CodingKey {
        case layerSchemaVersion = "layer_schema_version", file, url, bytes, sha256
        case dataDate = "data_date", osmTimestamp = "osm_timestamp", role
    }

    init(from decoder: any Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        layerSchemaVersion = try c.decode(Int.self, forKey: .layerSchemaVersion)
        file = try c.decode(String.self, forKey: .file)
        url = try c.decode(URL.self, forKey: .url)
        bytes = try c.decode(Int64.self, forKey: .bytes)
        sha256 = try c.decode(String.self, forKey: .sha256)
        let day = try c.decode(String.self, forKey: .dataDate)
        do {
            dataDate = try Date(day, strategy: .iso8601.year().month().day())
        } catch {
            throw DecodingError.dataCorruptedError(forKey: .dataDate, in: c, debugDescription: "not YYYY-MM-DD")
        }
        osmTimestamp = try c.decodeIfPresent(ISO8601Seconds.self, forKey: .osmTimestamp)?.date
        role = try c.decodeIfPresent(String.self, forKey: .role)
    }

    init(layerSchemaVersion: Int, file: String, url: URL, bytes: Int64, sha256: String,
         dataDate: Date, osmTimestamp: Date?, role: String?) {
        self.layerSchemaVersion = layerSchemaVersion; self.file = file; self.url = url; self.bytes = bytes
        self.sha256 = sha256; self.dataDate = dataDate; self.osmTimestamp = osmTimestamp; self.role = role
    }
}

/// `YYYY-MM-DDTHH:MM:SSZ`, the one timestamp form the data files use.
struct ISO8601Seconds: Decodable {
    let date: Date
    init(from decoder: any Decoder) throws {
        let text = try decoder.singleValueContainer().decode(String.self)
        do {
            date = try Date(text, strategy: .iso8601)
        } catch {
            throw DecodingError.dataCorrupted(.init(codingPath: decoder.codingPath, debugDescription: "not an ISO 8601 UTC timestamp"))
        }
    }
}

extension DecodingError {
    /// The failing field's path and reason, without any of the document's content.
    var fieldDescription: String {
        func path(_ context: Context) -> String {
            let p = context.codingPath.map { $0.intValue.map { "[\($0)]" } ?? $0.stringValue }.joined(separator: ".")
            return p.isEmpty ? "root" : p
        }
        switch self {
        case .keyNotFound(let key, let context): return "\(path(context)): missing \(key.stringValue)"
        case .typeMismatch(_, let context): return "\(path(context)): wrong type"
        case .valueNotFound(_, let context): return "\(path(context)): null not allowed"
        case .dataCorrupted(let context): return "\(path(context)): \(context.debugDescription)"
        @unknown default: return "unreadable"
        }
    }
}
```

```swift
/// The client half of the compatibility rule in `docs/data-format.md`: which `layer_schema_version`s this
/// package reads, and which entries of a layer a client takes.
enum ReadableVersions {
    /// Bump a layer's set when a reader for a new version ships; drop a version when its reader is removed.
    static let table: [Layer: Set<Int>] = Dictionary(uniqueKeysWithValues: Layer.allCases.map { ($0, Set([1])) })

    /// Roles this package knows. `nil` is the main file; `overlay` the tile file of trails and places.
    static let knownRoles: Set<String> = ["overlay"]

    enum Selection: Equatable, Sendable {
        /// The newest version the package reads, with every file of that version.
        case readable(version: Int, files: [ManifestEntry])
        /// No offered version is readable; the versions seen, newest first.
        case unreadable(offeredVersions: [Int])
    }

    /// `nil` when the layer offers nothing this package recognises (no entries, or only unknown roles).
    static func select(_ entries: [ManifestEntry], for layer: Layer, readable: Set<Int>? = nil) -> Selection? {
        let readable = readable ?? table[layer] ?? []
        let known = entries.filter { $0.role == nil || knownRoles.contains($0.role ?? "") }
        let versions = Set(known.map(\.layerSchemaVersion)).sorted(by: >)
        guard let newest = versions.first(where: readable.contains) else {
            return versions.isEmpty ? nil : .unreadable(offeredVersions: versions)
        }
        return .readable(version: newest, files: known.filter { $0.layerSchemaVersion == newest })
    }
}
```

import Foundation

/// Every path under the storage root. Nothing else in the package builds a path.
///
/// ```
/// <root>/manifest.json, manifest.meta.json, sources.json, sources.meta.json
/// <root>/packs/<region-id | base-id>/pack.json
/// <root>/packs/<…>/<layer>/<file>
/// <root>/downloads/<file>, <file>.resume
/// ```
struct StorageLayout: Sendable {
    let root: URL

    var manifest: CachedDocument {
        CachedDocument(dataURL: root.appending(path: "manifest.json"), metaURL: root.appending(path: "manifest.meta.json"))
    }
    var sources: CachedDocument {
        CachedDocument(dataURL: root.appending(path: "sources.json"), metaURL: root.appending(path: "sources.meta.json"))
    }
    var packsDirectory: URL { root.appending(path: "packs", directoryHint: .isDirectory) }
    var downloadsDirectory: URL { root.appending(path: "downloads", directoryHint: .isDirectory) }

    func packDirectory(_ id: PackID) -> URL { packsDirectory.appending(path: id.directoryName, directoryHint: .isDirectory) }
    func recordURL(_ id: PackID) -> URL { packDirectory(id).appending(path: "pack.json") }
    func layerDirectory(_ id: PackID, layer: Layer) -> URL { packDirectory(id).appending(path: layer.rawValue, directoryHint: .isDirectory) }
    func fileURL(_ id: PackID, layer: Layer, fileName: String) -> URL { layerDirectory(id, layer: layer).appending(path: fileName) }
    func downloadURL(fileName: String) -> URL { downloadsDirectory.appending(path: fileName) }
    func resumeDataURL(fileName: String) -> URL { downloadsDirectory.appending(path: fileName + ".resume") }

    /// `Application Support/Maqs` in the app's container.
    static func defaultRoot() throws -> URL {
        do {
            let support = try FileManager.default.url(for: .applicationSupportDirectory, in: .userDomainMask, appropriateFor: nil, create: true)
            return support.appending(path: "Maqs", directoryHint: .isDirectory)
        } catch {
            throw StorageError.cannotCreateDirectory("Application Support")
        }
    }
}

```swift
import Foundation

/// A fetched document and its fetch metadata, written atomically. `read()` is `nil` unless both halves exist.
struct CachedDocument: Sendable {
    struct Meta: Codable, Sendable, Equatable {
        var etag: String?
        var fetchedAt: Date
    }

    let dataURL: URL
    let metaURL: URL

    func read() -> (data: Data, meta: Meta)? {
        guard let data = try? Data(contentsOf: dataURL),
              let metaData = try? Data(contentsOf: metaURL),
              let meta = try? JSONDecoder().decode(Meta.self, from: metaData)
        else { return nil }
        return (data, meta)
    }

    func write(data: Data, meta: Meta) throws {
        do {
            try data.write(to: dataURL, options: .atomic)
            try JSONEncoder().encode(meta).write(to: metaURL, options: .atomic)
        } catch {
            throw StorageError.writeFailed(dataURL.lastPathComponent)
        }
    }

    func touch(fetchedAt: Date) throws {
        guard let current = read() else { return }
        var meta = current.meta
        meta.fetchedAt = fetchedAt
        do {
            try JSONEncoder().encode(meta).write(to: metaURL, options: .atomic)
        } catch {
            throw StorageError.writeFailed(metaURL.lastPathComponent)
        }
    }
}
```

```swift
import Foundation

/// One installed file as `pack.json` records it. Paths are relative: the container moves between launches.
struct RecordFile: Codable, Sendable, Equatable {
    let fileName: String
    let role: String?
    let schemaVersion: Int
    let sha256: String
    let bytes: Int64
    let dataDate: Date
}

/// `pack.json`: what is installed for one pack. Readers trust only files this names.
struct PackRecord: Codable, Sendable, Equatable {
    let id: PackID
    var release: String
    var files: [Layer: [RecordFile]]
}

/// One file of an installed pack, ready for `MaqsTerrain` and `MaqsData` to open.
public struct InstalledFile: Sendable, Equatable {
    /// The file on disk.
    public let url: URL
    /// `nil` for the main file, `"overlay"` for the tile file of trails and places.
    public let role: String?
    /// The `layer_schema_version` the file was written with.
    public let schemaVersion: Int
    /// The manifest's SHA-256, verified at install; `nil` for a file the app bundled itself.
    public let sha256: String?
    public let bytes: Int64
    /// The `data_date` of the entry; `nil` for a bundled file.
    public let dataDate: Date?
}

/// An installed pack: the files per layer, as recorded in `pack.json` or registered by the app.
public struct InstalledPack: Sendable, Equatable {
    public let id: PackID
    /// The data release the files came from, or `"bundled"`.
    public let release: String
    public let files: [Layer: [InstalledFile]]
    /// `true` when the app registered the file from its own bundle (``Maqs/registerBundledBasePack(id:basemap:)``).
    public let bundled: Bool
    /// Bytes on disk, summed over every file.
    public var bytes: Int64 { files.values.flatMap { $0 }.reduce(0) { $0 + $1.bytes } }
}
```

```swift
import Foundation

/// Owns the storage root: creates it, keeps it out of backups, reads and writes `pack.json`, moves files into place.
struct PackStore: Sendable {
    let layout: StorageLayout

    init(root: URL) throws {
        layout = StorageLayout(root: root)
        for directory in [layout.root, layout.packsDirectory, layout.downloadsDirectory] {
            do {
                try FileManager.default.createDirectory(at: directory, withIntermediateDirectories: true)
            } catch {
                throw StorageError.cannotCreateDirectory(directory.lastPathComponent)
            }
        }
        var root = layout.root
        var values = URLResourceValues()
        values.isExcludedFromBackup = true
        do {
            try root.setResourceValues(values)
        } catch {
            throw StorageError.cannotCreateDirectory(root.lastPathComponent)
        }
    }

    /// `nil` when nothing is installed; `corruptRecord` when `pack.json` exists but cannot be read.
    func record(for id: PackID) throws -> PackRecord? {
        let url = layout.recordURL(id)
        guard FileManager.default.fileExists(atPath: url.path()) else { return nil }
        guard let data = try? Data(contentsOf: url), let record = try? JSONDecoder().decode(PackRecord.self, from: data) else {
            throw StorageError.corruptRecord(id)
        }
        return record
    }

    /// Every readable record. A corrupt one is logged and skipped so the rest of the catalog still works.
    func records() -> [PackID: PackRecord] {
        var result: [PackID: PackRecord] = [:]
        let names = (try? FileManager.default.contentsOfDirectory(atPath: layout.packsDirectory.path())) ?? []
        for name in names {
            let id: PackID
            if name.hasPrefix("region-") { id = .region(String(name.dropFirst("region-".count))) }
            else if name.hasPrefix("base-") { id = .base(String(name.dropFirst("base-".count))) }
            else { continue }
            do {
                if let record = try record(for: id) { result[id] = record }
            } catch {
                logger.error("pack record unreadable: \(name, privacy: .public)")
            }
        }
        return result
    }

    /// Writes `pack.json` atomically. Call it last, after every file it names is in place.
    func write(_ record: PackRecord) throws {
        let url = layout.recordURL(record.id)
        do {
            try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
            try JSONEncoder().encode(record).write(to: url, options: .atomic)
        } catch {
            throw StorageError.writeFailed("pack.json")
        }
    }

    /// Deletes `pack.json` first, so no reader finds a half-deleted pack, then the directory.
    func removePack(_ id: PackID) throws {
        let record = layout.recordURL(id)
        do {
            if FileManager.default.fileExists(atPath: record.path()) { try FileManager.default.removeItem(at: record) }
            if FileManager.default.fileExists(atPath: layout.packDirectory(id).path()) {
                try FileManager.default.removeItem(at: layout.packDirectory(id))
            }
        } catch {
            throw StorageError.writeFailed(id.directoryName)
        }
    }

    /// Moves a verified download over the previous file of that layer in one `rename(2)`, which replaces atomically.
    func moveIntoPlace(from source: URL, to destination: URL) throws {
        do {
            try FileManager.default.createDirectory(at: destination.deletingLastPathComponent(), withIntermediateDirectories: true)
        } catch {
            throw StorageError.cannotCreateDirectory(destination.deletingLastPathComponent().lastPathComponent)
        }
        let result: Int32 = source.withUnsafeFileSystemRepresentation { from in
            destination.withUnsafeFileSystemRepresentation { to in
                guard let from, let to else { return -1 }
                return rename(from, to)
            }
        }
        guard result == 0 else { throw StorageError.writeFailed(destination.lastPathComponent) }
    }

    func installedPack(from record: PackRecord) -> InstalledPack {
        var files: [Layer: [InstalledFile]] = [:]
        for (layer, recorded) in record.files {
            files[layer] = recorded.map {
                InstalledFile(url: layout.fileURL(record.id, layer: layer, fileName: $0.fileName), role: $0.role,
                              schemaVersion: $0.schemaVersion, sha256: $0.sha256, bytes: $0.bytes, dataDate: $0.dataDate)
            }
        }
        return InstalledPack(id: record.id, release: record.release, files: files, bundled: false)
    }

    /// Removes, under each pack directory, files its record does not name and stray `pack.json.tmp` files.
    /// `downloads/` is left alone: partial and completed downloads are reused after a hash check.
    func sweep() {
        let fm = FileManager.default
        for (id, record) in records() {
            let named = Set(record.files.flatMap { layer, files in files.map { layout.fileURL(id, layer: layer, fileName: $0.fileName).path() } })
            let directory = layout.packDirectory(id)
            guard let enumerator = fm.enumerator(at: directory, includingPropertiesForKeys: [.isRegularFileKey]) else { continue }
            for case let url as URL in enumerator {
                guard (try? url.resourceValues(forKeys: [.isRegularFileKey]).isRegularFile) == true else { continue }
                if url.lastPathComponent == "pack.json" { continue }
                if url.lastPathComponent == "pack.json.tmp" || !named.contains(url.path()) {
                    try? fm.removeItem(at: url)
                    logger.info("swept orphan \(url.lastPathComponent, privacy: .public)")
                }
            }
        }
    }
}
```

```swift
public struct BoundingBox: Sendable, Hashable {
    public let minLon: Double
    public let minLat: Double
    public let maxLon: Double
    public let maxLat: Double

    public init(minLon: Double, minLat: Double, maxLon: Double, maxLat: Double) {
        self.minLon = minLon; self.minLat = minLat; self.maxLon = maxLon; self.maxLat = maxLat
    }

    /// From a manifest `bbox` array `[minLon, minLat, maxLon, maxLat]`; `nil` unless it has four numbers.
    public init?(_ array: [Double]) {
        guard array.count == 4 else { return nil }
        self.init(minLon: array[0], minLat: array[1], maxLon: array[2], maxLat: array[3])
    }

    /// Whether a point lies inside or on the edge.
    public func contains(longitude: Double, latitude: Double) -> Bool {
        (minLon...maxLon).contains(longitude) && (minLat...maxLat).contains(latitude)
    }
}
```

```swift
import Foundation

/// Derives a ``Catalog`` from a manifest, the configured layers and the installed packs.
enum CatalogBuilder {
    /// The per-layer selection for one pack, over the configured layers the pack offers. `nil` if the pack is not listed.
    static func selections(manifest: Manifest, pack: PackID, layers: Set<Layer>) -> [Layer: ReadableVersions.Selection]? {
        let entries: (Layer) -> [ManifestEntry]?
        switch pack {
        case .region(let id):
            guard let region = manifest.regions.first(where: { $0.id == id }) else { return nil }
            entries = region.entries(for:)
        case .base(let id):
            guard let base = manifest.base.first(where: { $0.id == id }) else { return nil }
            entries = base.entries(for:)
        }
        var result: [Layer: ReadableVersions.Selection] = [:]
        for layer in layers {
            if let offered = entries(layer), let selection = ReadableVersions.select(offered, for: layer) {
                result[layer] = selection
            }
        }
        return result
    }

    static func build(manifest: Manifest, fetchedAt: Date, layers: Set<Layer>, installed: [PackID: InstalledPack]) -> Catalog {
        let attribution = manifest.attribution.map {
            Attribution(text: $0.text, licence: $0.licence, url: $0.url, layers: $0.layers.compactMap(Layer.init(rawValue:)))
        }
        let regions = manifest.regions.map { region in
            summary(.region(region.id), names: region.name, bbox: BoundingBox(region.bbox), manifest: manifest, layers: layers, installed: installed)
        }
        let basePacks = manifest.base.compactMap { base -> PackSummary? in
            let summary = summary(.base(base.id), names: [:], bbox: nil, manifest: manifest, layers: layers, installed: installed)
            return summary.layers.isEmpty ? nil : summary
        }
        return Catalog(release: manifest.release, createdAt: manifest.createdAt, fetchedAt: fetchedAt,
                       attribution: attribution, regions: regions, basePacks: basePacks)
    }

    private static func summary(_ id: PackID, names: [String: String], bbox: BoundingBox?, manifest: Manifest,
                                layers: Set<Layer>, installed: [PackID: InstalledPack]) -> PackSummary {
        let selections = selections(manifest: manifest, pack: id, layers: layers) ?? [:]
        var availability: [Layer: LayerAvailability] = [:]
        var total: Int64 = 0
        for (layer, selection) in selections {
            switch selection {
            case .readable(let version, let files):
                let bytes = files.reduce(0) { $0 + $1.bytes }
                total += bytes
                let main = files.first { $0.role == nil } ?? files[0]
                availability[layer] = .available(bytes: bytes, schemaVersion: version, dataDate: main.dataDate, osmTimestamp: main.osmTimestamp)
            case .unreadable(let offered):
                availability[layer] = .unreadable(offeredVersions: offered)
            }
        }
        let status = status(selections: selections, release: manifest.release, installed: installed[id])
        return PackSummary(id: id, names: names, bbox: bbox, layers: availability, totalBytes: total, status: status)
    }

    /// `installed` when every readable configured layer matches by SHA-256; `updateAvailable` when any differs
    /// (bytes = changed + missing layers); `partiallyInstalled` when layers are only missing. Bundled packs are
    /// always `installed`: the app owns that file.
    static func status(selections: [Layer: ReadableVersions.Selection], release: String, installed: InstalledPack?) -> PackStatus {
        guard let installed else { return .notInstalled }
        if installed.bundled { return .installed(release: installed.release) }
        var changed: Int64 = 0
        var missing: Set<Layer> = []
        var missingBytes: Int64 = 0
        for (layer, selection) in selections {
            guard case .readable(_, let files) = selection else { continue }
            let bytes = files.reduce(0) { $0 + $1.bytes }
            guard let local = installed.files[layer], !local.isEmpty else {
                missing.insert(layer); missingBytes += bytes; continue
            }
            if Set(local.compactMap(\.sha256)) != Set(files.map(\.sha256)) { changed += bytes }
        }
        if changed > 0 { return .updateAvailable(release: release, bytes: changed + missingBytes) }
        if !missing.isEmpty { return .partiallyInstalled(missing: missing) }
        return .installed(release: installed.release)
    }
}
```

```swift
import Foundation

/// When a cached document is good enough.
public enum RefreshPolicy: Sendable {
    /// Use the cache while it is younger than the configured maximum age; fetch otherwise.
    case ifStale
    /// Always ask the server, with `If-None-Match` so an unchanged document costs no body.
    case always
}

/// Small-document GETs with the package's User-Agent and conditional requests. Not for pack files.
struct HTTPClient: Sendable {
    enum Response: Sendable, Equatable {
        case ok(Data, etag: String?)
        case notModified
        case status(Int)
    }

    let session: URLSession
    let userAgent: String

    func get(_ url: URL, ifNoneMatch etag: String?) async throws -> Response {
        var request = URLRequest(url: url, cachePolicy: .useProtocolCachePolicy)
        request.setValue(userAgent, forHTTPHeaderField: "User-Agent")
        if let etag { request.setValue(etag, forHTTPHeaderField: "If-None-Match") }
        let (data, response) = try await session.data(for: request)
        guard let http = response as? HTTPURLResponse else { return .status(0) }
        switch http.statusCode {
        case 200: return .ok(data, etag: http.value(forHTTPHeaderField: "ETag"))
        case 304: return .notModified
        default: return .status(http.statusCode)
        }
    }
}
```

```swift
/// Fetches, validates and caches `manifest.json`. On any failure the cached manifest stays what it was.
struct ManifestClient: Sendable {
    let http: HTTPClient
    let cache: CachedDocument
    let url: URL
    let maxAge: Duration
    let now: @Sendable () -> Date

    private var host: String { url.host() ?? "" }

    /// The cached manifest, if there is one and it still decodes.
    func cached() -> (manifest: Manifest, fetchedAt: Date)? {
        guard let (data, meta) = cache.read(), let manifest = try? Manifest.decode(data, manifestHost: host) else { return nil }
        return (manifest, meta.fetchedAt)
    }

    func load(policy: RefreshPolicy) async throws -> (manifest: Manifest, fetchedAt: Date) {
        let cached = cached()
        if policy == .ifStale, let cached, now().timeIntervalSince(cached.fetchedAt) < maxAge.seconds {
            return cached
        }
        let etag = cache.read()?.meta.etag
        let response: HTTPClient.Response
        do {
            response = try await http.get(url, ifNoneMatch: cached == nil ? nil : etag)
        } catch {
            logger.error("manifest fetch failed: \(error.localizedDescription, privacy: .public)")
            throw ManifestError.network(statusCode: nil)
        }
        switch response {
        case .notModified:
            guard let cached else { throw ManifestError.network(statusCode: 304) }
            try cache.touch(fetchedAt: now())
            logger.info("manifest unchanged")
            return (cached.manifest, now())
        case .status(429):
            throw ManifestError.rateLimited
        case .status(let code):
            throw ManifestError.network(statusCode: code)
        case .ok(let data, let newETag):
            let manifest = try Manifest.decode(data, manifestHost: host)
            try cache.write(data: data, meta: .init(etag: newETag, fetchedAt: now()))
            logger.info("manifest fetched: \(manifest.release, privacy: .public), \(data.count) bytes")
            return (manifest, now())
        }
    }
}

extension Duration {
    var seconds: TimeInterval {
        let (s, attos) = components
        return TimeInterval(s) + TimeInterval(attos) / 1e18
    }
}
```

```swift
import Foundation

/// Strict decoding of `sources.json` (`sources_version` 1). Unknown fields pass; wrong types and non-HTTPS URLs fail.
enum SourcesDocument {
    static let supportedVersion = 1

    private struct Document: Decodable {
        let sources_version: Int
        let layers: Layers
        struct Layers: Decodable { let basemap: [Source]; let terrain: [Source] }
        struct Source: Decodable {
            let id: String, provider: String, tiles: String, tilejson: URL, schema: String, format: String
            let tile_size: Int?, min_zoom: Int, max_zoom: Int, attribution: [String]
        }
    }

    static func decode(_ data: Data) throws -> OnlineSources {
        struct Probe: Decodable { let sources_version: Int }
        guard let version = try? JSONDecoder().decode(Probe.self, from: data).sources_version else {
            throw SourcesError.invalid("sources_version missing or not an integer")
        }
        guard version == supportedVersion else { throw SourcesError.unsupportedVersion(version) }
        let document: Document
        do {
            document = try JSONDecoder().decode(Document.self, from: data)
        } catch let error as DecodingError {
            throw SourcesError.invalid(error.fieldDescription)
        } catch {
            throw SourcesError.invalid("not valid JSON")
        }
        func convert(_ s: Document.Source) throws -> TileSource {
            guard s.tiles.lowercased().hasPrefix("https://"), s.tilejson.scheme?.lowercased() == "https" else {
                throw SourcesError.invalid("\(s.id): URLs must be https")
            }
            return TileSource(id: s.id, provider: s.provider, tiles: s.tiles, tilejson: s.tilejson, schema: s.schema,
                              format: s.format, tileSize: s.tile_size, minZoom: s.min_zoom, maxZoom: s.max_zoom, attribution: s.attribution)
        }
        return OnlineSources(version: version, basemap: try document.layers.basemap.map(convert), terrain: try document.layers.terrain.map(convert))
    }
}
```

```swift
import Foundation

/// `sources.json`: cached copy first, bundled copy as the fallback, refreshed on request.
struct SourcesClient: Sendable {
    let http: HTTPClient
    let cache: CachedDocument
    let url: URL
    let bundled: URL
    let maxAge: Duration
    let now: @Sendable () -> Date

    /// The copy of `config/sources.json` shipped in the package; `scripts/update-fixtures.sh` keeps it in sync and CI checks it.
    static var bundledURL: URL {
        // The resource is declared in Package.swift; a missing one is a packaging error, not a runtime condition.
        Bundle.module.url(forResource: "sources", withExtension: "json")
            ?? URL(filePath: "/missing/sources.json")
    }

    /// The best copy available without a request: cached if it decodes, else bundled.
    func current() -> OnlineSources? {
        if let (data, _) = cache.read(), let sources = try? SourcesDocument.decode(data) { return sources }
        guard let data = try? Data(contentsOf: bundled), let sources = try? SourcesDocument.decode(data) else {
            logger.error("bundled sources.json unreadable")
            return nil
        }
        return sources
    }

    func refresh(policy: RefreshPolicy) async throws -> OnlineSources {
        let cached = cache.read()
        if policy == .ifStale, let cached, now().timeIntervalSince(cached.meta.fetchedAt) < maxAge.seconds,
           let sources = try? SourcesDocument.decode(cached.data) {
            return sources
        }
        let response: HTTPClient.Response
        do {
            response = try await http.get(url, ifNoneMatch: cached?.meta.etag)
        } catch {
            throw SourcesError.network(statusCode: nil)
        }
        switch response {
        case .notModified:
            guard let cached, let sources = try? SourcesDocument.decode(cached.data) else { throw SourcesError.network(statusCode: 304) }
            try cache.touch(fetchedAt: now())
            return sources
        case .status(let code):
            throw SourcesError.network(statusCode: code)
        case .ok(let data, let etag):
            let sources = try SourcesDocument.decode(data)
            try cache.write(data: data, meta: .init(etag: etag, fetchedAt: now()))
            logger.info("sources.json fetched, \(data.count) bytes")
            return sources
        }
    }
}
```

```swift
import CryptoKit
import Foundation

/// Streaming SHA-256 of a file, 1 MiB at a time, so a 400 MB basemap never sits in memory.
enum FileHash {
    static func sha256(of url: URL) throws -> String {
        let handle = try FileHandle(forReadingFrom: url)
        defer { try? handle.close() }
        var hasher = SHA256()
        while let chunk = try handle.read(upToCount: 1 << 20), !chunk.isEmpty {
            hasher.update(data: chunk)
        }
        return hasher.finalize().map { String(format: "%02x", $0) }.joined()
    }
}
```

```swift
import Foundation
import Synchronization

/// Why a single transfer did not complete.
enum TransferError: Error, Equatable {
    case http(Int)
    case transport(String)
    /// Cancelled by us; the resume data, when the server supports ranges, is already written to the request's `resumeDataURL`.
    case cancelled(resumeData: Data?)
    case fileMove
}

/// Delegate-driven `URLSession` download tasks with async callers, usable with a background configuration.
///
/// Each task's `taskDescription` is its file name, so a task that completes after a relaunch (when no caller is
/// waiting) still lands under `orphanDirectory/<fileName>` and is picked up by the next install.
final class DownloadSession: NSObject, URLSessionDownloadDelegate, Sendable {
    struct Request: Sendable {
        let url: URL
        let fileName: String
        let destination: URL
        let resumeDataURL: URL
    }

    private struct Pending {
        var continuation: CheckedContinuation<Void, any Error>?
        let request: Request
        let progress: @Sendable (Int64) -> Void
        var moved = false
        var moveFailed = false
    }

    private let pending = Mutex<[Int: Pending]>([:])
    private let tasksByURL = Mutex<[String: URLSessionDownloadTask]>([:])
    private let backgroundCompletion = Mutex<(@Sendable () -> Void)?>(nil)
    private let sessionBox = Mutex<URLSession?>(nil)
    private let userAgent: String
    private let orphanDirectory: URL

    init(configuration: URLSessionConfiguration, userAgent: String, orphanDirectory: URL) {
        self.userAgent = userAgent
        self.orphanDirectory = orphanDirectory
        super.init()
        configuration.httpAdditionalHeaders = (configuration.httpAdditionalHeaders ?? [:]).merging(["User-Agent": userAgent]) { _, new in new }
        sessionBox.withLock { $0 = URLSession(configuration: configuration, delegate: self, delegateQueue: nil) }
    }

    private var session: URLSession {
        // Set once in init; the optional only exists because `self` is the delegate.
        sessionBox.withLock { $0 } ?? URLSession.shared
    }

    /// Downloads to `request.destination`, replacing any file there. Resumes from `request.resumeDataURL` when present.
    func download(_ request: Request, progress: @escaping @Sendable (Int64) -> Void) async throws {
        try await withCheckedThrowingContinuation { (continuation: CheckedContinuation<Void, any Error>) in
            let task: URLSessionDownloadTask
            if let resumeData = try? Data(contentsOf: request.resumeDataURL) {
                task = session.downloadTask(withResumeData: resumeData)
                try? FileManager.default.removeItem(at: request.resumeDataURL)
            } else {
                var urlRequest = URLRequest(url: request.url, cachePolicy: .useProtocolCachePolicy)
                urlRequest.setValue(userAgent, forHTTPHeaderField: "User-Agent")
                task = session.downloadTask(with: urlRequest)
            }
            task.taskDescription = request.fileName
            pending.withLock { $0[task.taskIdentifier] = Pending(continuation: continuation, request: request, progress: progress) }
            tasksByURL.withLock { $0[request.url.absoluteString] = task }
            task.resume()
        }
    }

    /// Cancels the task for `url`, keeping resume data next to the destination when the server allows it.
    func cancel(url: URL) {
        guard let task = tasksByURL.withLock({ $0[url.absoluteString] }) else { return }
        let resumeURL = pending.withLock { $0[task.taskIdentifier]?.request.resumeDataURL }
        task.cancel { data in
            if let data, let resumeURL { try? data.write(to: resumeURL, options: .atomic) }
        }
    }

    /// iOS: the app delegate's completion handler, invoked after the session has delivered all its events.
    func setBackgroundCompletionHandler(_ handler: @escaping @Sendable () -> Void) {
        backgroundCompletion.withLock { $0 = handler }
    }

    // MARK: URLSessionDownloadDelegate

    func urlSession(_ session: URLSession, downloadTask: URLSessionDownloadTask, didFinishDownloadingTo location: URL) {
        let status = (downloadTask.response as? HTTPURLResponse)?.statusCode ?? 0
        guard status == 200 else { return }   // the error body is not a file; didCompleteWithError reports the status
        let destination = pending.withLock { $0[downloadTask.taskIdentifier]?.request.destination }
            ?? orphanDirectory.appending(path: downloadTask.taskDescription ?? UUID().uuidString)
        do {
            try FileManager.default.createDirectory(at: destination.deletingLastPathComponent(), withIntermediateDirectories: true)
            if FileManager.default.fileExists(atPath: destination.path()) { try FileManager.default.removeItem(at: destination) }
            try FileManager.default.moveItem(at: location, to: destination)
            pending.withLock { $0[downloadTask.taskIdentifier]?.moved = true }
        } catch {
            pending.withLock { $0[downloadTask.taskIdentifier]?.moveFailed = true }
            logger.error("could not keep download \(destination.lastPathComponent, privacy: .public)")
        }
    }

    func urlSession(_ session: URLSession, downloadTask: URLSessionDownloadTask, didWriteData bytesWritten: Int64,
                    totalBytesWritten: Int64, totalBytesExpectedToWrite: Int64) {
        pending.withLock { $0[downloadTask.taskIdentifier]?.progress }?(totalBytesWritten)
    }

    func urlSession(_ session: URLSession, task: URLSessionTask, didCompleteWithError error: (any Error)?) {
        let entry = pending.withLock { $0.removeValue(forKey: task.taskIdentifier) }
        if let url = task.originalRequest?.url?.absoluteString ?? entry?.request.url.absoluteString {
            tasksByURL.withLock { $0[url] = nil }
        }
        guard let entry, let continuation = entry.continuation else { return }   // an orphan from a relaunch
        if let error {
            let nsError = error as NSError
            if nsError.domain == NSURLErrorDomain && nsError.code == NSURLErrorCancelled {
                continuation.resume(throwing: TransferError.cancelled(resumeData: nsError.userInfo[NSURLSessionDownloadTaskResumeData] as? Data))
            } else {
                continuation.resume(throwing: TransferError.transport(nsError.localizedDescription))
            }
            return
        }
        let status = (task.response as? HTTPURLResponse)?.statusCode ?? 0
        guard status == 200 else { continuation.resume(throwing: TransferError.http(status)); return }
        guard entry.moved, !entry.moveFailed else { continuation.resume(throwing: TransferError.fileMove); return }
        continuation.resume()
    }

    func urlSessionDidFinishEvents(forBackgroundURLSession session: URLSession) {
        guard let handler = backgroundCompletion.withLock({ $0 }) else { return }
        DispatchQueue.main.async { handler() }   // UIKit requires the main thread
    }
}
```

```swift
import Foundation
import Synchronization

/// Installs one pack: downloads every file of the chosen entries (at most two at once), verifies size and
/// SHA-256, moves the files into place, writes `pack.json` last, then sweeps files the record no longer names.
struct Installer: Sendable {
    struct FileJob: Sendable, Equatable {
        let layer: Layer
        let entry: ManifestEntry
    }

    struct Plan: Sendable {
        let id: PackID
        let release: String
        /// Files to download; layers already installed with the same SHA-256s are not in it.
        let jobs: [FileJob]
        /// The record to write when every job has been verified and moved.
        let record: PackRecord
        var totalBytes: Int64 { jobs.reduce(0) { $0 + $1.entry.bytes } }
    }

    let store: PackStore
    let session: DownloadSession
    let concurrency = 2

    /// Decides what to download. Throws `layerUnreadable` before any request when a configured layer is unreadable.
    static func plan(id: PackID, release: String, selections: [Layer: ReadableVersions.Selection], existing: PackRecord?) throws -> Plan {
        var jobs: [FileJob] = []
        var files = existing?.files ?? [:]
        for (layer, selection) in selections.sorted(by: { $0.key.rawValue < $1.key.rawValue }) {
            switch selection {
            case .unreadable:
                throw DownloadError.layerUnreadable(layer)
            case .readable(let version, let entries):
                if let have = existing?.files[layer], Set(have.map(\.sha256)) == Set(entries.map(\.sha256)) { continue }
                jobs += entries.map { FileJob(layer: layer, entry: $0) }
                files[layer] = entries.map {
                    RecordFile(fileName: $0.file, role: $0.role, schemaVersion: version, sha256: $0.sha256, bytes: $0.bytes, dataDate: $0.dataDate)
                }
            }
        }
        return Plan(id: id, release: release, jobs: jobs, record: PackRecord(id: id, release: release, files: files))
    }

    func run(_ plan: Plan, progress: @escaping @Sendable (DownloadProgress) -> Void, onVerifying: @escaping @Sendable () -> Void) async throws {
        let total = plan.totalBytes
        let received = Mutex<[String: Int64]>([:])
        let report: @Sendable () -> Void = {
            progress(DownloadProgress(bytesReceived: received.withLock { $0.values.reduce(0, +) }, totalBytes: total))
        }
        try await withThrowingTaskGroup(of: Void.self) { group in
            var remaining = plan.jobs[...]
            var running = 0
            func startNext() {
                guard let job = remaining.popFirst() else { return }
                running += 1
                group.addTask {
                    try await self.fetch(job) { bytes in
                        received.withLock { $0[job.entry.file] = bytes }
                        report()
                    }
                }
            }
            for _ in 0..<concurrency { startNext() }
            while running > 0 {
                try await group.next()
                running -= 1
                startNext()
            }
        }
        onVerifying()
        for job in plan.jobs { try verify(job) }
        for job in plan.jobs {
            try store.moveIntoPlace(from: store.layout.downloadURL(fileName: job.entry.file),
                                    to: store.layout.fileURL(plan.id, layer: job.layer, fileName: job.entry.file))
        }
        try store.write(plan.record)
        store.sweep()
        logger.info("installed \(plan.id.directoryName, privacy: .public): \(plan.jobs.count) files, \(total) bytes")
    }

    /// Reuses a completed file in `downloads/` when its hash already matches; otherwise downloads (resuming if possible).
    private func fetch(_ job: FileJob, progress: @escaping @Sendable (Int64) -> Void) async throws {
        try Task.checkCancellation()
        let destination = store.layout.downloadURL(fileName: job.entry.file)
        if FileManager.default.fileExists(atPath: destination.path()) {
            if (try? FileHash.sha256(of: destination)) == job.entry.sha256 {
                progress(job.entry.bytes)
                return
            }
            try? FileManager.default.removeItem(at: destination)
        }
        let request = DownloadSession.Request(url: job.entry.url, fileName: job.entry.file, destination: destination,
                                              resumeDataURL: store.layout.resumeDataURL(fileName: job.entry.file))
        do {
            try await withTaskCancellationHandler {
                try await session.download(request, progress: progress)
            } onCancel: {
                session.cancel(url: job.entry.url)
            }
        } catch TransferError.cancelled {
            throw DownloadError.cancelled
        } catch TransferError.http(let code) {
            logger.error("download of \(job.entry.file, privacy: .public) failed: HTTP \(code)")
            throw DownloadError.network(statusCode: code)
        } catch is TransferError {
            throw DownloadError.network(statusCode: nil)
        } catch is CancellationError {
            throw DownloadError.cancelled
        }
    }

    private func verify(_ job: FileJob) throws {
        let url = store.layout.downloadURL(fileName: job.entry.file)
        let attributes = try? FileManager.default.attributesOfItem(atPath: url.path())
        let size = (attributes?[.size] as? NSNumber)?.int64Value ?? -1
        guard size == job.entry.bytes else {
            try? FileManager.default.removeItem(at: url)
            throw DownloadError.sizeMismatch(file: job.entry.file)
        }
        guard try FileHash.sha256(of: url) == job.entry.sha256 else {
            try? FileManager.default.removeItem(at: url)
            logger.error("checksum mismatch: \(job.entry.file, privacy: .public)")
            throw DownloadError.checksumMismatch(file: job.entry.file)
        }
    }
}
```

`Sources/MaqsCore/Maqs.swift`:

```swift
import Foundation

/// The entry point of `MaqsCore`: region discovery, downloads, installed packs, and the online sources.
///
/// Create one instance per app with a ``MaqsConfiguration``, read ``state`` from SwiftUI, call
/// ``refreshCatalog(policy:)`` to learn what the latest data release offers, and ``install(_:)`` to download a pack.
/// `MaqsTerrain` and `MaqsData` open the files that ``installedPack(_:)`` returns.
public actor Maqs {
    public let configuration: MaqsConfiguration
    /// Observable state for SwiftUI.
    @MainActor public let state: MaqsState

    private let store: PackStore
    private let manifestClient: ManifestClient
    private let sourcesClient: SourcesClient
    private nonisolated let downloadSession: DownloadSession
    private let installer: Installer
    private var manifest: (manifest: Manifest, fetchedAt: Date)?
    private var bundled: [PackID: InstalledPack] = [:]
    private var installs: [PackID: Task<Void, any Error>] = [:]
    private var queueTail: Task<Void, Never>?
    private var lastProgress: [PackID: Int64] = [:]

    /// Creates the storage root (excluded from backup), sweeps orphans, and restores the installed packs and the
    /// cached catalog. Throws ``StorageError`` when the root cannot be created.
    @MainActor public init(configuration: MaqsConfiguration) throws {
        self.configuration = configuration
        let root = try configuration.storageDirectory ?? StorageLayout.defaultRoot()
        let store = try PackStore(root: root)
        store.sweep()
        self.store = store
        let http = HTTPClient(session: URLSession(configuration: configuration.urlSessionConfiguration), userAgent: configuration.fullUserAgent)
        manifestClient = ManifestClient(http: http, cache: store.layout.manifest, url: configuration.manifestURL,
                                        maxAge: configuration.catalogMaxAge, now: configuration.now)
        sourcesClient = SourcesClient(http: http, cache: store.layout.sources, url: configuration.sourcesURL,
                                      bundled: SourcesClient.bundledURL, maxAge: configuration.catalogMaxAge, now: configuration.now)
        let downloadConfiguration: URLSessionConfiguration
        if let identifier = configuration.backgroundSessionIdentifier {
            downloadConfiguration = .background(withIdentifier: identifier)
            downloadConfiguration.sessionSendsLaunchEvents = true
            downloadConfiguration.isDiscretionary = false
        } else {
            downloadConfiguration = configuration.urlSessionConfiguration
        }
        downloadSession = DownloadSession(configuration: downloadConfiguration, userAgent: configuration.fullUserAgent,
                                          orphanDirectory: store.layout.downloadsDirectory)
        installer = Installer(store: store, session: downloadSession)
        let state = MaqsState()
        let records = store.records()
        state.packs = records.mapValues { .installed(store.installedPack(from: $0)) }
        if let cached = manifestClient.cached() {
            manifest = cached
            let installed = records.mapValues { store.installedPack(from: $0) }
            state.catalog = CatalogBuilder.build(manifest: cached.manifest, fetchedAt: cached.fetchedAt, layers: configuration.layers, installed: installed)
        }
        self.state = state
    }

    // MARK: Discovery

    /// Loads the latest manifest (per `policy`) and publishes the catalog. On failure the previous catalog stays,
    /// ``MaqsState/lastRefreshError`` is set, and the error is thrown.
    public func refreshCatalog(policy: RefreshPolicy = .ifStale) async throws -> Catalog {
        do {
            let loaded = try await manifestClient.load(policy: policy)
            manifest = loaded
            let catalog = buildCatalog()
            await publish { $0.catalog = catalog; $0.lastRefreshError = nil }
            return catalog
        } catch let error as ManifestError {
            await publish { $0.lastRefreshError = .manifest(error) }
            throw MaqsError.manifest(error)
        } catch let error as StorageError {
            await publish { $0.lastRefreshError = .storage(error) }
            throw MaqsError.storage(error)
        }
    }

    // MARK: Packs

    /// Downloads and installs every configured layer of `pack` that is missing or changed. A second call for a
    /// pack already installing joins it. Packs install one at a time, in call order.
    public func install(_ pack: PackID) async throws {
        if let running = installs[pack] {
            try await running.value
            return
        }
        guard let manifest else { throw MaqsError.download(.noCatalog) }
        guard let selections = CatalogBuilder.selections(manifest: manifest.manifest, pack: pack, layers: configuration.layers),
              !selections.isEmpty
        else { throw MaqsError.download(.notInCatalog(pack)) }
        let existing = try? store.record(for: pack)   // a corrupt record means a full reinstall
        let plan: Installer.Plan
        do {
            plan = try Installer.plan(id: pack, release: manifest.manifest.release, selections: selections, existing: existing)
        } catch let error as DownloadError {
            throw MaqsError.download(error)
        }
        let previous = queueTail
        let installer = installer
        let task = Task<Void, any Error> {
            await previous?.value
            try Task.checkCancellation()
            await self.publish { $0.packs[pack] = .downloading(DownloadProgress(bytesReceived: 0, totalBytes: plan.totalBytes)) }
            try await installer.run(plan) { progress in
                Task { await self.report(progress, for: pack) }
            } onVerifying: {
                Task { await self.publish { $0.packs[pack] = .verifying } }
            }
        }
        installs[pack] = task
        queueTail = Task { _ = try? await task.value }
        defer { installs[pack] = nil; lastProgress[pack] = nil }
        do {
            try await task.value
            let installed = store.installedPack(from: plan.record)
            let catalog = buildCatalog()
            await publish { $0.packs[pack] = .installed(installed); $0.catalog = catalog }
        } catch {
            let wrapped = wrap(error)
            let fallback = installedPack(pack).map(PackState.installed) ?? .notInstalled
            let failed: PackState = wrapped == .download(.cancelled) ? fallback : .failed(wrapped)
            await publish { $0.packs[pack] = failed }
            throw wrapped
        }
    }

    /// Cancels an install in progress. Resume data is kept, so the next ``install(_:)`` continues where it stopped.
    public func cancelInstall(_ pack: PackID) {
        installs[pack]?.cancel()
    }

    /// Deletes a downloaded pack, or unregisters a bundled one without touching the app's file.
    public func remove(_ pack: PackID) async throws {
        installs[pack]?.cancel()
        if bundled[pack] != nil {
            bundled[pack] = nil
        } else {
            do { try store.removePack(pack) } catch let error as StorageError { throw MaqsError.storage(error) }
        }
        let catalog = buildCatalog()
        await publish { $0.packs[pack] = .notInstalled; $0.catalog = catalog }
    }

    /// Registers a base pack the app ships in its own bundle (ADR 0007). Not persisted: call it on every launch.
    public func registerBundledBasePack(id: String, basemap url: URL) async throws {
        guard let attributes = try? FileManager.default.attributesOfItem(atPath: url.path()),
              let bytes = (attributes[.size] as? NSNumber)?.int64Value
        else { throw MaqsError.storage(.fileNotFound(url.lastPathComponent)) }
        let pack = InstalledPack(id: .base(id), release: "bundled", files: [.basemap: [
            InstalledFile(url: url, role: nil, schemaVersion: 1, sha256: nil, bytes: bytes, dataDate: nil),
        ]], bundled: true)
        bundled[.base(id)] = pack
        let catalog = buildCatalog()
        await publish { $0.packs[.base(id)] = .installed(pack); $0.catalog = catalog }
    }

    /// The installed files of a pack, or `nil` when it is not installed.
    public func installedPack(_ pack: PackID) -> InstalledPack? {
        if let bundled = bundled[pack] { return bundled }
        guard let record = try? store.record(for: pack) else { return nil }
        return store.installedPack(from: record)
    }

    /// Bytes on disk: installed files per pack and pending downloads.
    public func diskUsage() -> DiskUsage {
        let byPack = store.records().mapValues { store.installedPack(from: $0).bytes }
        let downloads = (try? FileManager.default.contentsOfDirectory(at: store.layout.downloadsDirectory, includingPropertiesForKeys: [.fileSizeKey])) ?? []
        let pending = downloads.reduce(Int64(0)) { $0 + Int64((try? $1.resourceValues(forKeys: [.fileSizeKey]).fileSize) ?? 0) }
        return DiskUsage(bytesByPack: byPack, downloadsBytes: pending)
    }

    // MARK: Online sources

    /// The online providers, or `nil` when ``MaqsConfiguration/onlineTiles`` is `false`.
    public var onlineSources: OnlineSources? {
        configuration.onlineTiles ? sourcesClient.current() : nil
    }

    /// Refreshes `sources.json` from `main`. `nil` without a request when online tiles are off.
    public func refreshOnlineSources(policy: RefreshPolicy = .ifStale) async throws -> OnlineSources? {
        guard configuration.onlineTiles else { return nil }
        do { return try await sourcesClient.refresh(policy: policy) }
        catch let error as SourcesError { throw MaqsError.sources(error) }
        catch let error as StorageError { throw MaqsError.storage(error) }
    }

    #if os(iOS)
    /// Forward `application(_:handleEventsForBackgroundURLSession:completionHandler:)` here. The handler runs
    /// on the main thread once the session has delivered every event.
    public nonisolated func handleEventsForBackgroundURLSession(identifier: String, completionHandler: @escaping @Sendable () -> Void) {
        guard identifier == configuration.backgroundSessionIdentifier else { return }
        downloadSession.setBackgroundCompletionHandler(completionHandler)
    }
    #endif

    // MARK: Private

    private func installedPacks() -> [PackID: InstalledPack] {
        var result = store.records().mapValues { store.installedPack(from: $0) }
        for (id, pack) in bundled { result[id] = pack }
        return result
    }

    private func buildCatalog() -> Catalog? {
        guard let manifest else { return nil }
        return CatalogBuilder.build(manifest: manifest.manifest, fetchedAt: manifest.fetchedAt, layers: configuration.layers, installed: installedPacks())
    }

    /// Publishes progress at most every 256 KiB, and always at completion.
    private func report(_ progress: DownloadProgress, for pack: PackID) async {
        let last = lastProgress[pack] ?? -1
        guard progress.bytesReceived - last >= 262_144 || progress.bytesReceived == progress.totalBytes else { return }
        lastProgress[pack] = progress.bytesReceived
        guard case .downloading? = await MainActor.run({ state.packs[pack] }) else { return }
        await publish { $0.packs[pack] = .downloading(progress) }
    }

    private func wrap(_ error: any Error) -> MaqsError {
        switch error {
        case let e as MaqsError: e
        case let e as DownloadError: .download(e)
        case let e as StorageError: .storage(e)
        case is CancellationError: .download(.cancelled)
        default: .download(.network(statusCode: nil))
        }
    }

    private func publish(_ update: @MainActor @Sendable (MaqsState) -> Void) async {
        let state = state
        await MainActor.run { update(state) }
    }
}
```

The `report` guard against `.downloading` keeps a late progress callback from overwriting `.verifying` or `.installed`.

```markdown
## 0014 — `MaqsCore`: one entry point, manifest-driven discovery, verified installs

**Date:** 2026-10-16 · **Status:** accepted (owner decisions 2026-10-16)

**Context.** Phase 4 of the brief is the Swift package. It is built in four sub-projects (Core, Terrain, Data, UI with the demo); this ADR covers the first: `Package.swift`, `swift.yml`, the fixtures, and `MaqsCore`. The owner asked that the package also discover regions: fetch what the latest data release offers and tell the app, through `releases/latest/download/manifest.json` and never the GitHub REST API.

**Decisions.**
- Discovery is data and observable state only: a `Catalog` of regions and base packs with names, bbox, per-layer bytes and schema version, and an install status; apps draw their own list. No region picker view, now or in `MaqsUI`.
- Base packs both ways: an app can register a bundled base pack (ADR 0007) for the current launch, and `MaqsCore` can download a base pack from the manifest like a region. Registration is not persisted, because the app bundle's path changes across app updates.
- The online opt-out of ADR 0008 is the configuration flag `onlineTiles`; `false` makes `onlineSources` `nil`, so `MaqsUI` and `MaqsTerrain` never see a tile URL. The manifest and `sources.json` fetches stay allowed; they carry no position. This closes the question ADR 0012 left open: an empty `sources.json` is not the opt-out.
- The `test` region's outputs are committed under `Tests/MaqsTestSupport/Fixtures/` (today <measured> KB, cap 8192 KB, `swift.yml` enforces it), the one exception to the no-binary rule. `swift test` runs from a clean checkout with no Python; `scripts/update-fixtures.sh` regenerates them and the bundled `sources.json`.
- One public `actor Maqs` over internal parts; `MaqsTerrain` and `MaqsData` take file URLs and `TileSource` values, never `MaqsCore` types.
- Storage: `Application Support/Maqs/`, excluded from backup; `packs/<region-id|base-id>/pack.json` names the installed files per layer; `downloads/` holds in-flight and completed files, reused after a hash check. Every file is size- and SHA-256-checked after download; files move into place with `rename(2)`; `pack.json` is written last. A crash leaves either the old record and its files or the new ones.
- Refresh policy: `.ifStale` (cache younger than `catalogMaxAge`, default 24 h) or `.always` with `If-None-Match`. The package never fetches on a timer and never retries inside a call. Every manifest URL must be HTTPS on the manifest's own host.
- The readable schema versions live in one table (`ReadableVersions.table`, `[1]` per layer); this is the client half of ADR 0012's rule.
- Warnings are errors through `SwiftSetting.treatAllWarnings(as: .error)` in `Package.swift` (tools version 6.2); no `unsafeFlags`, so the package stays consumable.

**Verified on 2026-10-16.**

| <platform behaviour found in Task 5 / Task 12, if any> | | |

**Rejected.**
- Separate public components wired by the app: four stable types instead of one, and every app rebuilding the install invariants.
- Building the fixtures in CI: a Python toolchain on the macOS runner and before every local `swift test`.
- Persisting the bundled base pack registration: a stale path after an app update.
- Retrying inside the package: the app decides when to try again; a 429 must never become a tight loop.

**CONTRADICTS BRIEF (minor):** the brief's Phase 4 list says "manifest fetch with caching and ETag handling" and leaves the base pack to ADR 0007; both are implemented as above. CLAUDE.md said the bundled `sources.json` is "synced by the build"; it is copied by `scripts/update-fixtures.sh` and checked by CI, because SwiftPM cannot copy a file from outside a target at build time.

**Consequences.**
- Apps call `refreshCatalog()` when they want fresh data, read `MaqsState`, and show catalog statuses themselves.
- `MaqsTerrain` (sub-project 2) and `MaqsData` (sub-project 3) open `InstalledFile.url`s and never import `MaqsCore`.
- The package is not tagged until sub-project 4; `v0.1.0` is a git tag or a release created with `--latest=false` (ADR 0013).
- `swift.yml` runs on package changes only; data-only and docs-only pushes spend no macOS minutes.
```
