Everything in this folder except this file is generated by `scripts/update-map-assets.sh` from pinned
VersaTiles releases. This file is written by hand and is not touched by the script.

(https://github.com/versatiles-org/versatiles-fonts, release v3.0.0, `noto_sans.tar.gz`,

## Sprite (`sprite/`) and default styles (`styles/`): CC0 1.0

The sprite sheet `base` (icons from Maki and Temaki, both CC0) comes from
https://github.com/versatiles-org/versatiles-style/releases/tag/v7.0.1 (`sprites.tar.gz`,
SHA-256 `3dfed482a0c48caa2762ae08badcd1c4b5d4a3901c1508ecc30b73a992f10b65`).
The default styles are derived from the `muted-terrain` and `muted-dark-terrain` styles in the same
release (`styles.tar.gz`, SHA-256 `088bbfb96b0807c1d90e2e1a464f680c458e9ba23341547d37ad6e12c14d6e41`),
which declare the licence CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/
The changes (source and URL tokens, four recoloured groups, hidden POI layers) are listed in
`pipeline/src/maqs/map_style.py`.
